# ANZ ECF — Order Management Prototype

A high-fidelity React prototype of the front end for an ecommerce order management system, built for designer-to-developer handoff. No backend — all data is hardcoded. The focus is visual fidelity, interaction design, and clickability so engineers can reference exact behavior when building the real implementation in their own stack.

Sibling project to `anz-admin-service` (the Woolworths picking/fulfilment admin portal prototype), reusing the same shell pattern: persona switching, store/country context, Shadcn design system.

See `CLAUDE.md` for architecture details and conventions.

## Getting started

```
npm install
npm run dev
```

Opens at http://localhost:5173
